# WMD-NickNijskens_RemedialAssignment

## Purpose

The API is written in Nodejs and is designed to obtain and overview position and system data of players of the supplied game.

The Admin Panel is written in HTML5/Javascript and is designed to view and delete collected data.

The game is made in the Unity Game Engine. The player has to make hotdogs and give them to customers. Rounds take 2 minutes to complete.

## Getting Started

To get started with the project, follow these steps:

1. Copy the `.env.template` file to a new file called `.env`.

2. Run the following command to build and start the API using Docker Compose:
    ```
    docker-compose up --build
    ```

3. Run the `Dev5-WMD-NickNijskens_RA.exe` file in the `game_build` map to play the game

4. Open the admin panel by browsing to localhost:3000 in your browser
